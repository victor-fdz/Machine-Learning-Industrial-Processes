# 🧪 Predicting Industrial Outcomes: A Machine Learning Analysis of Chemical Industrial Processes Data

Machine learning project focused on predicting fragrance shelf-life stability from manufacturing sensor data.

### 🎯 Objectives
- Explore manufacturing data and identify potential anomalies.
- Investigate relationships between process variables and product stability.
- Develop regression models to predict shelf-life.
- Estimate prediction uncertainty and interpret model predictions.

### 🛠️ Technologies
Python · Pandas · NumPy · Scikit-learn · XGBoost · SHAP · Matplotlib · Seaborn

### 📊 Key Results
The final XGBoost model achieved an **R² of 0.771** and an **MAE of 0.762 months** on the test set. Quantile regression was also used to estimate 90% prediction intervals.

### ⚠️ Dataset
This project uses a **simulated but realistic industrial dataset**. All data are synthetic and do not represent real manufacturing operations or proprietary information.
